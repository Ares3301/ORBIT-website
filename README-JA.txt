GitHub Pagesの更新
1. ZIPを展開します。
2. ORBIT-websiteリポジトリの既存ファイルと同じ場所へ、展開した内容をアップロードします。
3. index.htmlはリポジトリ直下に置き、assetsフォルダもまとめて更新してください。

パソコンで確認
JavaScriptモジュールを使用するため、index.htmlの直接ダブルクリックでは動作しない場合があります。
Pythonがある場合は展開したフォルダで python -m http.server 8000 を実行し、ブラウザで http://localhost:8000 を開いてください。

ISS位置と一部の観測画像にはインターネット接続が必要です。
