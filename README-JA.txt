ORBIT 太陽系マップ — サイト一式

HTML、CSS、JavaScript、画像、天体データ、ライセンス表記を収録しています。
ビルドやnpmのインストールは不要です。

PCで動かす方法（Python 3が必要）
1. ZIPを展開します。
2. index.htmlがあるフォルダーでターミナルを開きます。
3. Windowsでは次のコマンドを実行します。
   py -m http.server 8000 --bind 127.0.0.1
   Mac/Linuxでは python3 -m http.server 8000 --bind 127.0.0.1
4. ブラウザで http://localhost:8000 を開きます。
5. 終了はターミナルで Ctrl+C。

JavaScriptのモジュールを使うため、index.htmlのダブルクリックでは正常に動かない場合があります。
静的サイトを扱えるWebサーバーにも、このフォルダーの内容を配置できます。

操作
ドラッグ：回転／ホイール・ピンチ：ズーム
H：UIの表示切り替え／N：天体名の表示切り替え
音声：最初のクリック・タップ・キー操作で再生開始

素材の出典・ライセンスはassets内のCREDITSとLICENSEファイル、およびサイトの「表示について」を参照してください。
サイトの公開権限設定はこのZIPには含まれません。配置先の設定に従います。
